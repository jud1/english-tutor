# Evaluation Instructions

## 1. Overview

This guide describes the evaluation process, types, criteria, and usage for the English tutor system. All evaluations should consider tutor memory to personalize feedback and track progress.

## 2. Evaluation Types

- **Initial Evaluation:** Full diagnostic, all sections (profile, CEFR, grammar, vocabulary, listening, reading, speaking, writing, emotional/confidence). Required before starting the course.
- **Biweekly Evaluation:** Quick progress check. Includes only key sections: grammar, vocabulary, short listening/reading, brief writing/speaking, emotional/confidence. For frequent progress tracking; can be replaced by monthly if too frequent.
- **Monthly Evaluation:** More complete than biweekly, but less than quarterly. Includes most sections except full profile and CEFR. For deeper progress review and study plan adjustment.
- **Quarterly Evaluation:** Comprehensive, similar to initial. Includes all sections and is used to redefine objectives and strategies. For milestone assessment, strategy review, and goal setting.

## 3. Tutor Memory Usage

- **Initial Evaluation:** Does not require prior context or tutor memory. Only uses the student's current profile, goals, and skills.
- **Periodic Evaluations (Biweekly, Monthly, Quarterly):** Should consider tutor memory. Use all available information to personalize feedback, track improvements, and identify areas for adjustment.

## 5. Evaluation Content & Criteria

### Content Types & Definitions

- **Profile & Goals:** Personal info, objectives.
- **CEFR Placement:** Level estimation.
- **Grammar:** Exercises, error correction.
- **Vocabulary:** General and technical.
- **Listening:** Audio comprehension.
- **Reading:** Text analysis.
- **Speaking:** Oral tasks, roleplay.
- **Writing:** Email, summaries, reports.
- **Emotional/Confidence:** Self-assessment.

## 6. Evaluation Rubrics

Scoring scale: 0–100  
CEFR levels: A1 → C2  
Criteria per skill include:

- Listening: comprehension, detail recognition, inference
- Speaking: fluency, pronunciation, grammar control, lexical range
- Reading: global understanding, scanning, vocabulary recognition
- Writing: structure, tone, accuracy, cohesion, conciseness

## 7. Frequency Recommendation

- **Biweekly** is ideal for intensive tracking, but monthly is sufficient for most adult learners.
- **Monthly** is recommended for regular progress review.
- **Quarterly** is best for strategic assessment and planning.

*Session corrections or reviews can be added later if needed for more granular feedback.*
