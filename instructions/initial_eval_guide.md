# INITIAL EVALUATION GUIDE

Duration: 90–120 minutes

Sections:
1. Profile and goals
2. CEFR placement estimation
3. Grammar assessment
4. General and technical vocabulary
5. Listening (2 pieces)
6. Reading (2 texts)
7. Speaking (intro + short roleplay)
8. Writing (email + short technical summary)
9. Emotional/confidence check

Output:  
A JSON file validated against `evaluation.initial.schema.json`  
+ updates to `progress.json`.
