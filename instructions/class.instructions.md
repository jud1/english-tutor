# Class Instructions

## 1. Overview
Guidelines for structuring, conducting, and documenting each class session.

## 2. Class Structure
- Opening: greetings, objectives
- Main activity: topic introduction, exercises, roleplay, discussion
- Feedback: mistakes, corrections, tips
- Closing: summary, homework, next steps

## 3. Activity Types
- Speaking practice (roleplay, debates)
- Listening exercises
- Reading comprehension
- Writing tasks
- Technical English scenarios

## 4. Interaction Rules
- Classes mainly in English
- Spanish only for critical explanations
- Encourage active participation
- Respectful and supportive environment

## 5. Feedback Methods
- Immediate correction of mistakes
- Written report of errors and corrections
- Suggestions for improvement

- List of recommended materials, links, or apps for class use
